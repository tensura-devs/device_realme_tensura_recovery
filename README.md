GPU     | Mali-G57 MC2
Memory  | 4GB/8GB RAM
Shipped OS | Android 12 with Realme UI 3.0
Storage | 128GB /256GB UFS 2.2
Battery | Li-Po 5000 mAh, non‑removable
Display | 6.4‑inch Super AMOLED, 1080×2400 pixels (FHD+), 90Hz refresh rate
